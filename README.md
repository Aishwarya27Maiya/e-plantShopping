# e-plantShopping

Paradise Nursery — e-plantShopping project.

A responsive houseplant shopping experience built with React, Vite, and Redux Toolkit. Browse plant collections, add favorites to your cart, adjust quantities, and review your order total.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```

## Deploy to GitHub Pages

1. Push this project to a public GitHub repository.
2. In the repository settings, open **Pages** and choose **GitHub Actions** as the build and deployment source.
3. Push to the `main` branch. The included workflow builds the app and deploys the `dist` directory.

The app uses hash-based navigation and a relative Vite base path so project-site URLs work on GitHub Pages.
